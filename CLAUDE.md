# Cooking App

Personal PWA (French UI) for a single user on an Android phone: food diary with calorie/macro goals, photo
analysis of a plate (Gemini, Claude optional), barcode lookup (Open Food Facts), food search (Ciqual 2025),
home-made dishes with cook mode. Built as a clean-room rebuild of YAZIO/MyFitnessPal features
(`replica/recon.md`); never copy their code, assets or copy.

Live: https://gauthierdesmaizieres-sketch.github.io/cooking-app/ — repo `gauthierdesmaizieres-sketch/cooking-app` (public).

## Stack
- Front: React 19 + Vite 8, plain CSS with design tokens (`replica/design/tokens.json` -> `tokens.css`,
  `node replica/design/gen-css.mjs`), primitives in `src/ui.jsx`, hash routes in `src/App.jsx`, all data
  calls in `src/data.js`, pure helpers + unit tests in `src/lib.js` / `src/lib.test.js`.
- Back: Supabase (Postgres + RLS, anonymous auth, Storage bucket `photos`, Edge Functions in
  `supabase/functions/`: `scan-photo`, `barcode`, `delete-account`). Migrations in `supabase/migrations/`
  (Ciqual data is a migration, generated by `scripts/import_ciqual.py`).
- Auth: no email. Each browser gets an anonymous account on first launch (`src/screens/Welcome.jsx`).
  `scan-photo` also requires the owner's `APP_ACCESS_CODE` (header `x-app-code`, asked once in the app).

## Run locally (Windows, Docker Desktop must be running)
```
npx supabase start -x studio,realtime,imgproxy,vector,logflare,supavisor
npx supabase functions serve --env-file supabase/functions/.env   # Gemini key lives here (gitignored)
npx vite --port 5174 --strictPort
```
`.env.local` holds the local Supabase URL/anon key (`npx supabase status`).

## Tests (run before every commit)
- `npm test` (unit), `cd supabase/functions && deno test` (functions), `npx playwright test` (e2e, ~35 s;
  AI is mocked, test users are created per worker and cleaned up), RLS:
  `docker exec -i supabase_db_Cooking_App psql -U postgres -v ON_ERROR_STOP=1 -q < supabase/tests/rls.sql`.
- If e2e hangs for minutes, a module failed to compile: `curl localhost:5174/src/<file>` returns 500.

## Deploy
- Push the working branch `publish` to GitHub `main`: `git push origin publish:main`. Local `main` holds an
  older history that contains a leaked key and must never be pushed.
- `.github/workflows/deploy.yml` builds and publishes Pages; `.github/workflows/supabase.yml` pushes
  migrations, functions, function secrets and auth settings. Repo secrets: `SUPABASE_ACCESS_TOKEN`,
  `SUPABASE_DB_PASSWORD`, `GEMINI_API_KEY`, `APP_ACCESS_CODE`; variable `SUPABASE_PROJECT_REF`.
- Supabase free plan: custom auth email templates are refused (no own SMTP); Gemini free tier is slow
  (15–45 s) and sometimes overloaded (fallback model in `scan-photo`).

## Conventions
- Never write secrets in tracked files (`.env.example` keeps empty values). GitHub push protection is on.
- Edit code with the Edit tool, not ad-hoc Python string replaces (two past breakages from escaping).
- Project docs: `replica/` (recon, architecture, features.csv parity matrix, build-log, bugs, deploy).
